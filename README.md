# PA-Keyboard

R code, simulation results, and a companion application for **PA-Keyboard**, an exposure-guided Bayesian interval design for borrowing adult information in pediatric phase I dose-finding.

This repository accompanies the manuscript:

> **An exposure-guided Bayesian interval design for borrowing adult information in pediatric phase I dose-finding**  
> Zengyue Zheng, Yue Yang, Bosheng Li, Fangrong Yan, and Liyun Jiang  
> Research Center of Biostatistics and Computational Pharmacy, China Pharmaceutical University, Nanjing, China.

## Available materials

| Resource | Contents | Access |
|---|---|---|
| Simulation code and results | R scripts and saved results for the main simulation study and sensitivity analyses | [`PA_Keyboard_Rcode/`](PA_Keyboard_Rcode/) |
| Companion application | Downloadable PA-Keyboard application package | [Releases](https://github.com/ZhengZengYue/PA-Keyboard/releases) |

The simulation study compares PA-Keyboard with Keyboard and PA-CRM. The supplied code and saved results support reproduction of the manuscript tables and figures.

## Download and use

### Reproduce the simulation study

Select **Code → Download ZIP**, extract the archive, and open `PA_Keyboard_Rcode/`. The README in that folder provides the software requirements, execution instructions, and guidance for regenerating tables and figures from the saved results.

### Use the companion application

Visit [Releases](https://github.com/ZhengZengYue/PA-Keyboard/releases), download `PA-Keyboard_app.zip` from the **Assets** section, and extract the entire archive. Follow the instructions included in the application package to launch it.

**The application is downloaded separately from Releases. It is not included in Code → Download ZIP or the automatically generated Source code archives.**
